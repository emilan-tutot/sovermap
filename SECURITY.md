# Sécurité

## Signaler une faille

Merci de **ne pas** ouvrir d’issue publique pour une faille de sécurité.

Utilisez le **signalement privé de GitHub** :
1. ouvrez l’onglet **Security** de ce dépôt ;
2. cliquez sur **Report a vulnerability** ;
3. décrivez la faille, l’adresse concernée et les étapes pour la reproduire.

Le signalement n’est visible que des mainteneurs. Une première réponse est donnée dès que possible. Une correction est publiée avec une note qui crédite l’auteur du signalement, s’il le souhaite.

## Périmètre

- Le site (pages, en-têtes, politique de sécurité du contenu).
- La collecte quotidienne et les fichiers de données publiés.
- Le code de ce dépôt et ses dépendances.

## Ce que le site ne fait pas

Le site n’a ni compte, ni formulaire, ni cookie. Il ne charge aucun service tiers dans le navigateur. Les données collectées sont affichées en texte, jamais interprétées comme du HTML.

## In English

Please do not open a public issue for a security vulnerability. Use GitHub’s private reporting instead: **Security** tab, then **Report a vulnerability**.
